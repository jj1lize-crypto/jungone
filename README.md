# jungwon

Static prototype for JUNG ONE: The Garden.

## Run locally

```sh
python3 -m http.server 8000
```

Then open http://127.0.0.1:8000/.

## Structure

- `index.html` — Korean version (main entry)
- `en.html` — English version
- `assets/jungone-main/` — optimized PNG/WebP image assets
- `assets/media/` — non-image demo media, such as voice and video
- `archive/` — older prototypes and experiments, kept for reference:
  - `archive/tv.html` — full-screen display garden (TV mode, no Q&A flow)
  - `archive/garden.html` — display garden
  - `archive/jungwon-greenlight-v*.html` — greenlight prototype iterations
  - `archive/jungwon-mobile-*.html` — mobile prototype iterations
  - `archive/index-re.html` — extended prototype page
